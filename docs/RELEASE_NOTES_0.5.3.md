# Inkleaf 0.5.3

- 阅读正文默认加宽到 1000 px，新增“排版”设置，可调最大宽度、铺满阅读区域及左右留白；实时生效并在本机保存。
- 新增 Graphviz 图表 1.0.0：离线渲染 `dot` / `graphviz` 代码块，支持查看源码与 HTML / PDF 导出。
- 新增 PlantUML 图表 1.0.0：配置本机或自建服务，渲染 `plantuml` / `puml` 围栏；未配置或失败时保留源码。不附带 Java 服务，不支持外部 include/import。
- 新增选文助手 1.0.0：统一连接兼容模型服务或本机 Ollama，提供解释、翻译、总结、流式结果、取消、复制及主动写回。密钥可由系统加密保存；无安全存储时仅本次会话有效。文档已变化时拒绝覆盖。
- 修复长路径、反链与未链接提及异步填入时，右栏撑宽并将正文预览挤成单字竖列的问题（#7）。共享右栏限制宽度，保持文档可读，兼容窄窗口和异常旧布局。
- 修复共享右栏拖拽宽度目标与方向，统一渲染完成后的大纲同步，避免主题切换与文档渲染交叠时回显旧内容。
- 更新源返回 404 时显示无法访问及可能原因，不再误报为“已经是最新版本”。私有仓库无法供未登录客户端匿名更新。

使用方式见 [阅读与服务指南](READING-AND-SERVICES.md)。模型和 PlantUML 需要用户自行配置服务；生成内容请核对后使用。

安装包提供 macOS ARM64、Linux x64 / ARM64 的 AppImage 与 deb；平台验证与附件以本次 Releases 为准。
