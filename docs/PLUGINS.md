# 插件中心

点击工具栏的拼图按钮，或选择 **文件 → 插件中心**。

- **已安装**：查看运行状态、权限和版本，启用、停用、重载或卸载插件。
- **发现插件**：浏览随软件附带的官方目录，可按名称、说明、作者搜索，或按分类筛选。安装前会显示版本与权限，安装完成后需要手动启用。
- **可用更新**：对比已安装版本与官方目录中的版本。外部插件可逐个更新；内置插件随墨页软件更新。

点击插件名称，在右侧查看介绍、使用示例和版本记录。提示块提供全部 24 种类型的写法、复制按钮和实际效果预览。同义类型共用配色；目前不提供折叠交互。

## 检查与安装更新

点击 **检查更新**，从 `Fovercon/Inkleaf` 仓库正式 `main` 分支的 `resources/plugin-catalog.json` 获取目录。不会在后台自动安装或启用代码。目录随软件附带，因此离线也能浏览与安装附带版本；联网失败会明确提示，并继续使用本地目录。检查时间显示在页首。

开发分支中新加的目录要合入 `main` 后才会成为在线来源；在此之前，在线请求可能返回 404，本地附带目录依然可用。

对于已安装的外部插件，点击详情页的 **更新至…**，确认版本与权限后更新。也可以选择 **从文件夹更新…** 导入作者提供的新版：插件 ID 必须相同，正式版本号必须更高。支持 `主版本.次版本.修订版本` 的数值比较，预发布版本暂不参与升级。目录中的文件会进行 SHA-256 完整性校验；校验值与目录由同一个官方来源提供，不代表独立作者签名。

替换前会暂存完整新版，替换失败会恢复旧文件；如果程序恰在替换中退出，下次扫描会恢复尚未提交的旧版。更新保留启停选择；运行中的插件会重新加载。文件替换成功后如插件自身启动报错，会显示错误，可重试或停用；此时不会宣称更新成功，也不自动回退到低版本。

未进入官方目录的插件不会被误报成「已是最新」，详情会提示从作者处获取新版。只有内置插件不能单独升级、重载或卸载。

## 本地插件

选择 **从文件夹安装…**，打开含 `ink.plugin.json` 和入口脚本的文件夹；安装完成后手动启用。启停选择会自动保存，渲染插件的启停立即更新文档预览。卸载会将外部插件移入系统废纸篓，失败保留原运行状态。

外部插件运行在隔离的 iframe 中，通过声明的 `render`（文档预览）和 `commands`（提供命令）权限扩展功能。插件不能直接使用宿主的文件访问桥接接口。

插件可以在 `ink.plugin.json` 中提供以下详情字段；纯文本显示，示例 Markdown 会经过清理：

```json
{
  "author": "作者名称",
  "category": "阅读",
  "description": "简短介绍",
  "usage": "启用后的使用方法",
  "minAppVersion": "0.5.1",
  "examples": [{ "title": "示例", "markdown": "> [!tip]\n> 提示内容" }],
  "changelog": [{ "version": "1.0.0", "notes": "首次发布" }]
}
```

## 维护官方目录

可读的外部插件源码位于 `resources/plugins/<插件 ID>/`，修改 manifest 的版本和记录后，执行 `npm run plugins:catalog` 重新生成分发目录，再运行 `npm run test:regressions` 和 `npm run test:plugin-center-ui`。目录分发采用有限的平铺 JSON 文件包，仅允许 JS、MJS、JSON；不会下载或执行原生安装器。

内置提示块的详情与版本由软件源码维护，目录中的对应记录用于展示和提示软件更新。新增或升级目录条目需要审阅源码、权限和兼容版本后合入正式分支。
