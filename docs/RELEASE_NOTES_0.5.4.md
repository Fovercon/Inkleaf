# 墨页 · Inkleaf 0.5.4

## 划词翻译与 AI 问询

- 原选文助手拆为可独立启停的“划词翻译”和“AI 问询”，保留原有连接与密钥，并继承旧助手的停用选择。
- 阅读视图和编辑器选文后出现操作条；翻译在附近浮窗显示，可切换语言、停止、复制或主动替换选文。可在划词设置开启“选中即译”，拖动选择和空选择不会发送请求。
- 解释与总结在右侧聊天栏显示，支持连续追问、清空会话、复制、Markdown、代码、表格与公式。引用图片点击后才加载，远程图片仅支持 HTTPS。
- 工具栏“模型”是应用级共用连接，停用插件后仍可配置。API Key 仅在主进程使用，系统加密不可用时仅保留本次运行。
- 修复 Linux 下流传输取消后可能一直等待连接关闭的问题；切换文档、关闭或停用对应插件会取消请求，窗口重载也会释放旧请求。写回前核对原文，避免覆盖新编辑。

## 图表服务

- PlantUML 插件升级至 1.1.0，提供官方免费服务、Kroki、本机及自定义预设，并正确区分两种传输协议。
- “测试连接”只发送固定演示图，不保存配置、不上传当前文档。保存设置后才会使用所选服务渲染文档图表；保密内容建议使用本机服务。
- Graphviz 与 Mermaid 继续离线渲染，无需外部服务。

## Linux 安装与更新

- **AppImage（x64 / ARM64）**：直接从当前用户拥有的可写目录运行原始 AppImage，支持检查、下载、保存并重启更新。不要从解压目录启动来测试自动替换。
- **deb（Ubuntu / Debian，x64 / ARM64）**：支持检查版本，更新通过发布页下载新版包后交给包管理器安装，例如 `sudo apt install ./Inkleaf-0.5.4-linux-x64.deb`，无需先卸载。deb 不提供软件内自动替换。
- AppImage 若缺 FUSE 可使用系统对应的 FUSE 兼容包；保留原文件和书库即可重新安装。两个安装方式共用本机配置，书库文档不随应用包删除。

## 使用说明

填写一次自己的模型服务地址、模型 ID 和可选 Key，翻译和问询即可共用。支持 OpenAI 兼容 Chat Completions 服务与本机 Ollama；应用不包含模型订阅或额度。生成内容请核对。现阶段不提供联网百科检索、整库分析或外部插件无提示调用模型的权限。

本版本提供 macOS Apple Silicon ZIP、Linux x64 / ARM64 AppImage 与 deb，每个包附 SHA-256 校验文件。macOS Intel 暂无安装包。
