# 创作与知识管理

从右上角的 **创作与知识工具** 打开各项工具，也可以在命令面板搜索工具名称。书库标题旁的 ⇄ 和首页的“最近书库”可直接切换文件夹。

## 文档历史与属性

保存 Markdown 文档前会记录旧内容。历史仅在本机应用数据目录保存，默认每篇保留最近 100 个不同内容版本；可在历史窗口调整为 2–10000。手动快照不会重复记录相同内容。选择版本可查看逐行差异，恢复前会保留当前内容；预览后文件发生变化时，恢复会停止，请重新打开历史窗口。

“文档属性”可编辑 YAML 的 `title`、`date`、`tags`，以及自定义文本、数字、布尔、空值和文本列表。列表每行一项。修改保留其他字段、注释与正文；复杂属性在源码中编辑。无效或重复键 YAML 会显示错误，不会自动修复。`title` 不会改变文件名。属性、表格、图片、链接、模板插入都可使用编辑器撤销。

## 搜索与批量修改

“书库搜索与替换”支持大小写、全字和正则选项。路径、标签、属性条件同时生效；路径是相对书库路径的包含匹配，标签包含其子层级，属性值为精确匹配。全字边界使用 Unicode 字母、数字和下划线。

先输入条件并预览替换，展开文件查看前后差异，勾选需要修改的文件，再应用。正则替换支持 `$1`、`$2` 等捕获组。更改条件后需重新预览。标签批量改名使用相同流程，处理精确标签和子标签、去除重复 YAML 标签，避开代码和链接。

预检查发现文件变动时整批不会开始；写入期间失败会停止，分别显示已完成、失败与未处理文件。已完成文件可以从各自历史恢复。预览有效期 15 分钟，切换书库后失效。

一次搜索限制为单篇 8 MB、范围 64 MB，超限请用路径过滤缩小范围。正则最多执行 1.5 秒；结果最多展示 1000 条，出现截断会明确提示。替换不会静默截断内容。

## 书库与布局

每个书库分别记忆标签页、当前文档与展开目录；切换前自动保存，保存失败时保持原书库。最近书库可以移除记录，文件不会被删除。

“阅读与写作布局”可保存、应用、重命名或删除布局，也提供两种预设。布局包含面板开合、宽度、专注及打字机状态，不包含文档正文。重命名前在“布局名称”输入新名称。

## 标签与引用

标签中的斜线表示层级，例如 `#项目/墨页`。父标签计数按文档去重；点击展开箭头查看子标签，点击名称查看所有子层级文档。

反向链接面板显示源路径、行号和上下文；未链接提及按当前文档名称或 `title` 做字面匹配，排除代码、已链接文本与 URL。双链会优先解析来源目录中的同名文档；目录限定名称可精确指向目标。

点击尚不存在的 `[[文档]]`，确认后可创建并打开。`[[./同级文档]]`、`[[../上级文档]]` 相对当前文档，其余目录路径相对书库根目录。新建不会覆盖已有文件，也不会越出当前书库。

## 每日笔记与模板

“打开今日笔记”默认使用本机日期创建 `日记/YYYY-MM-DD.md`；当天文件已存在则直接打开。可在“每日笔记设置”调整目录、日期格式和模板。日期格式须包含 `YYYY`、`MM`、`DD`，如 `YYYY/MM/DD`。

模板仅保存在本机。内置空白、会议记录、日记示例，可新建、编辑、删除；插入当前选区，或输入相对路径据此新建文档。支持 `{{title}}`、`{{date}}`、`{{time}}`，未知占位符保持原样。

## 表格、图片、链接与正文目录

把光标放在有效 Markdown 表格中，打开“表格行列与对齐”，可插入、删除行列，设置某列左对齐、居中或右对齐。不能删除表头或最后一列。

选中已有图片或链接，或把光标放在其源码内，打开相应属性工具即可回填修改；空白处也可插入。图片使用以下可往返扩展，宽高为 1–10000 的整数像素，留空则使用原始大小：

```markdown
![示意图](<assets/diagram.png>){width=480 height=320}
```

单独一行 `[TOC]` 会生成正文目录，支持重复标题的唯一锚点；代码块内保持原文。HTML 与 PDF 导出保留目录和图片尺寸。
