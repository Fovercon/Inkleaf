# Inkleaf 0.5.0

本版补齐本地创作与知识管理工具。源码版本已更新，安装包的发布状态以 GitHub Releases 为准。

- **历史与恢复**：自动与手动快照、逐行差异、版本恢复、可调整保留数量；历史只存在本机。
- **文档属性**：可视化编辑 YAML 标题、日期、标签与自定义属性，保留未修改字段、注释、正文和换行形式。
- **搜索与替换**：大小写、全字、正则，以及路径、标签和属性组合过滤；逐文件预览与选择替换，冲突保护和部分失败报告。
- **书库与布局**：最近书库、每库标签与目录状态恢复、命名布局和阅读／写作预设。
- **知识连接**：嵌套标签树、标签批量改名、反链上下文、未链接提及和断链创建文档。
- **写作工具**：每日笔记、模板管理、表格行列与对齐、图片尺寸及链接属性编辑、可导出的正文 `[TOC]` 目录。

统一入口位于右上角的 **创作与知识工具**，全文搜索快捷键直接打开增强搜索。详细操作见 [使用指南](KNOWLEDGE.md)。

现有 Markdown 文档无需迁移。当前书库会话沿用原格式，新历史与工具配置放在本机应用数据中；旧索引会自动重建。跨文件修改先保存编辑，保留旧内容快照；预览后的外部修改会阻止覆盖。普通文件系统不提供跨文件事务，运行中失败会明确报告已完成和未处理文件。
