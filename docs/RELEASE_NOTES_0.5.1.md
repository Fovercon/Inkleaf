# Inkleaf 0.5.1

插件中心升级为三栏管理页面，延续暖白纸面、墨色文字与叶绿色点缀，并适配深色主题及窄窗口。

- 新增「已安装／发现插件／可用更新」导航，支持搜索和分类。
- 插件详情展示作者、权限、用法、可复制示例、版本记录和最低软件版本。
- 附带可离线安装的官方插件目录，提供「阅读时间」和「外链标记」两个预览扩展。
- 支持检查官方目录更新、逐个更新外部插件，以及从本地文件夹升级；升级前展示权限，保留启停选择，并提供文件替换失败恢复。
- 修复提示块配色被主题色覆盖的问题，内置插件版本升为 0.1.1，新增全部 24 种类型的效果示例。

详见 [插件中心使用说明](PLUGINS.md)。在线目录来自 GitHub 正式分支；开发源码里的新目录合入 main 后才会上线。软件源码版本与安装包发布状态以各自实际状态为准。
