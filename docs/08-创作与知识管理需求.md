## 目标与边界

为本地 Markdown 书库补齐文档恢复、属性编辑、检索修改、工作区组织、知识连接和常用写作操作。六组均为必做；不以仅出现按钮或占位界面作为完成。

继续支持 macOS 与 Ubuntu / Debian 桌面；沿用已有 Markdown、YAML、标签、双链和本地图片行为。所有新增文档数据、历史和工作区设置留在本机，不加入云同步、账号、AI 语义检索或多人协作。在线插件市场不属于本轮。

交付沿用上一轮：验证后更新版本并推送 dev；正式发布、main 合并和替换本机安装分别按发布流程处理。

## 六组功能与验收

以下每条 FR 对应同编号 AC，均要求真实入口可达；文件修改类同时使用临时书库进行落盘验收。

| ID | 可观察行为 | 验收情景 |
|---|---|---|
| FR-H1 | 保存文档时自动保留内容不同的历史快照，支持手动快照。 | 连续保存不同内容，关闭重开后仍可按时间浏览；相同内容不重复占用版本。 |
| FR-H2 | 显示所选历史与当前内容的逐行差异，并可恢复。 | 恢复后编辑器、磁盘和预览一致；恢复前的当前版本可再次找回；取消不改文件。 |
| FR-H3 | 显示并允许调整每篇文档的历史保留数量，默认最近 100 个版本。 | 超限后保留最新版本；明确展示设置影响；历史写入失败不静默覆盖原文。 |
| FR-P1 | 属性面板编辑标题 title、日期 date、标签 tags。 | 编辑后 YAML 与正文预览正确更新，标签索引变化，重启后保存结果不丢失。 |
| FR-P2 | 支持新增、编辑、删除自定义标量属性与字符串列表。 | 修改一个属性不丢失其他属性、注释或正文；复杂嵌套值保留且提示在源码中编辑。 |
| FR-P3 | 不自动修复或覆盖无效 YAML。 | 无效、重复键或不支持的头部格式显示原因，保留原文；用户修好后可重试。 |
| FR-S1 | 全文搜索增加大小写、全字匹配、正则选项。 | 同一测试书库验证各开关结果差异；无效正则显示错误而非假装无结果。全字以 Unicode 字母、数字和下划线边界判定。 |
| FR-S2 | 支持路径、标签和 YAML 属性的组合过滤。 | 文本条件与所有过滤条件同时满足才返回；路径按书库相对路径匹配，属性按键及可选值过滤。 |
| FR-S3 | 批量替换先预览文件、匹配数量和前后内容，允许选择要修改的文件。 | 取消不落盘；仅修改选中文档；正则替换支持捕获组；空匹配不会无限循环。 |
| FR-S4 | 批量修改检测预览后的内容变化并保留修改前快照。 | 若预检查发现文件变动，整批不开始；写入期间失败即停止并显示已完成、失败、未处理文件，已完成内容可从历史恢复。 |
| FR-W1 | 提供最近书库列表和快捷切换入口。 | 从首页或书库入口直接切换；不存在的目录给出反馈并可从列表移除，不破坏当前书库。 |
| FR-W2 | 按书库保存并恢复其标签页、当前文档与目录展开状态。 | A、B 两个书库往返后各自恢复；切换前保存失败则留在原书库；旧会话仍能加载。 |
| FR-W3 | 命名保存、应用、重命名、删除阅读/写作布局。 | 保存并恢复编辑、预览、侧栏开合和宽度、专注与打字机状态；提供阅读/写作预设；不混入文档内容。 |
| FR-K1 | 标签按斜线层级展示为可展开树，父级可查看其子标签文档。 | #项目/墨页 和 #项目/研究 位于同一父级；父级计数按文档去重，旧平铺标签照常可用。 |
| FR-K2 | 标签批量改名支持预览，处理 YAML 标签与正文标签。 | 只改精确标签及其子层级；代码块、行内代码、链接 URL 与普通文字不被误改；目标标签重复时去重，写入遵循 FR-S4。 |
| FR-K3 | 反链显示命中行及上下文，并准确跳转。 | 同名不同目录的文档按目标路径区分，切换文档不显示旧请求的结果。 |
| FR-K4 | 展示当前文档名称或 title 的未链接提及。 | 排除当前文档和已链接文本、代码、URL；按字面名称匹配，允许中文子串匹配；点击跳到源文档行。 |
| FR-K5 | 点击未解析双链可创建目标文档。 | 用户确认后创建并打开书库内目标，支持相对目录；已有文件不覆盖、越界路径拒绝，创建失败给出反馈。 |
| FR-E1 | 提供每日笔记入口，使用本机日期。 | 默认在书库的“日记/YYYY-MM-DD.md”创建，当日已存在则打开；可设置目录和日期模板。 |
| FR-E2 | 管理 Markdown 模板并插入当前文档或据此新建文档。 | 可保存、编辑、删除模板，提供空白/会议/日记示例；替换 {{title}}、{{date}}、{{time}}，未知占位符保留原样。 |
| FR-E3 | 为光标所在 Markdown 表格提供插入、删除行列与对齐操作。 | 操作后列数和分隔行正确，转义竖线与代码中的竖线不误拆；无有效表格时提示并不改正文；编辑可撤销。 |
| FR-E4 | 提供图片尺寸、替代文字与链接文字/地址的编辑面板。 | 选中已有图片或链接可回填编辑，也可插入；图片尺寸使用可往返的 Markdown 扩展，预览和导出一致；取消不改内容。 |
| FR-E5 | 正文独立一行 [TOC] 渲染为可点击目录。 | 包含实际标题层级和重复标题的唯一锚点；代码块内标记保持原样；点击跳转，HTML/PDF 导出保留目录内容。 |

## 数据、错误与恢复规则（本次建议）

- 历史放在本机应用数据目录，不在用户书库生成历史文件；默认每篇保留最近 100 个不同内容版本，可调整。仅承诺捕获墨页看到的版本，不承诺记录软件关闭期间每一次外部修改。
- 修改前先保存当前编辑并生成快照。属性、表格、图片、链接及模板插入走编辑器的撤销链；跨文件替换、标签改名走可预览的批量操作。
- 恢复、批量替换、标签改名均不得覆盖预览后发生的外部修改。冲突时要求刷新预览；磁盘失败必须准确报告部分完成，不报告全部成功、不静默回滚覆盖外部内容。
- 保留已有文件名、正文、换行符、未编辑的 YAML 字段及注释；不以属性 title 改名文件，不以模板覆盖已有文件。
- 新建文档限定当前书库内；拒绝路径穿越和指向书库外的符号链接。插件隔离、图片访问边界与原有自动保存规则继续有效。
- 多书库为顺序切换；工作区为命名布局。不同书库之间不自动跨库搜索、合并标签或迁移文档。
- 单个文档中未链接提及按字面文本判断，不引入语义推断；复杂 Markdown/YAML 无法无损编辑时保留原文并给出原因。

## 交互与质量

沿用暖白纸面、墨色文字、叶绿色点缀及深色主题。新操作提供加载、空结果、错误和成功反馈；对话框有标题、键盘关闭、焦点恢复，长列表可滚动。实际窗口检查宽窄布局。

涉及数据正确性的断言以文件内容、历史内容、索引查询与编辑器状态为依据，不仅检查按钮存在。覆盖：正常、取消、无权限/磁盘错误、外部冲突、旧会话升级、不同书库隔离和重启恢复。macOS 本机验证，Linux x64/ARM64 沿用仓库 CI。
