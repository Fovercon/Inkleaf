## 两次审查

契约核对：逐项对照 Spec 和验收行为，没有延期项。工程核对：文件覆盖、历史失败、原子替换、预览冲突、旧会话、真实路径边界、正则资源限制、未链接误报、插件隔离、代码块语法、UI 更新与可撤销性。

发现并已关闭的 IMPLEMENT 问题：

- YAML 列表删除范围可能触及下一字段；空值紧邻注释时缺少分隔空格。新增 golden 后修复。
- 关闭弹窗后立刻打开另一工具，旧 DOM 尚未移除，焦点可能回到旧窗口。同步移除旧弹窗、限制焦点恢复；模板 CRUD/窄窗关闭通过。
- 批量标签改名后索引已更新但侧栏未刷新。修改完成与文件事件后刷新侧栏，UI 明确断言新标签可见。
- 引用式快捷链接可能被计为未链接提及。用 Markdown 引用表排除，补充负例。
- 搜索条件变化时旧批量预览仍可见。输入变化移除预览，需重新生成后应用。

没有未解决的 BLOCKER/HIGH 实现问题。历史与多文件写入不声称拥有系统级锁或多文件事务，行为与已授权设计一致。
