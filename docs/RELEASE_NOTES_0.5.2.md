# 墨页 · Inkleaf 0.5.2

本次正式版汇总 0.4.5 之后的创作、知识管理与插件中心改进。已安装 0.4.5 的 macOS 用户可在软件内检查、下载并安装更新。

## 创作与知识管理

- **历史与恢复**：自动与手动快照、版本差异及恢复，可调整保留数量；默认每篇最近 100 个版本，历史仅保存在本机。
- **文档属性**：可视化编辑 YAML 标题、日期、标签和自定义属性，保留未修改字段、注释与正文。
- **搜索与批量替换**：大小写、全字、正则及路径、标签、属性过滤；先预览与选择文件，保留快照并检测内容冲突。
- **书库与布局**：最近书库、快速切换、每库标签页与目录状态恢复、命名布局及阅读／写作预设。
- **知识连接**：嵌套标签、批量改名、反链上下文、未链接提及、断链创建文档。
- **写作工具**：每日笔记、模板、表格行列操作、图片与链接编辑，以及可导出的正文 `[TOC]` 目录。

统一入口位于右上角 **创作与知识工具**。详情见 [创作与知识管理指南](KNOWLEDGE.md)。

## 插件中心与界面

- 三栏插件中心提供 **已安装／发现插件／可用更新**，支持搜索、分类、作者与权限说明、用法、可复制示例及版本记录。
- 官方目录附带「阅读时间」「外链标记」两个可安装扩展，支持离线安装、在线目录检查、本地升级、失败恢复和启停状态保留。
- 内置提示块插件升至 **0.1.1**：修复所有类型都显示主题色的问题，提供全部 24 种类型的预览与写法。
- 按钮悬停约 0.3 秒显示用途及系统对应的快捷键；面板提示随展开／收起状态变化，支持键盘聚焦和动态弹窗。
- 完善插件启停、错误重试、安装与卸载失败反馈；调整书库栏、首页入口及标签识别。

插件操作见 [插件中心说明](PLUGINS.md)。

## 安装与兼容

- 提供 macOS Apple Silicon 更新 ZIP，以及 Linux x64、ARM64 的 AppImage 和 Debian／Ubuntu deb 包；每个安装包附 SHA-256 校验文件。
- 保留既有本地文档与会话格式；旧索引自动重建。跨文件批量修改不具备文件系统级跨文件事务，运行中失败会报告已完成与未处理文件，可通过本机历史恢复。
- macOS 包未经过 Developer ID 签名和公证，首次安装的系统授权说明见 [安装指南](INSTALLATION.md)。本次不提供 Windows 或 macOS Intel 安装包。
- 官方插件只按需安装和启用。Linux deb 属于系统包管理安装，软件内会提示新版本，安装需使用新版 deb；AppImage 支持软件内更新。
