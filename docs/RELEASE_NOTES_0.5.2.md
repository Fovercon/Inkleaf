# Inkleaf 0.5.2

为界面按钮增加统一的悬浮说明，方便通过图标识别操作。

- 鼠标停留约 300 毫秒显示用途，键盘聚焦同样可见；有快捷键的按钮会按当前系统显示组合键。
- 展开／收起面板的说明随当前状态变化，软件更新按钮保留实时状态提示。
- 覆盖工具栏、书库视图与切换、标签页关闭和动态弹窗中的按钮；插件管理按钮提供更具体的操作说明。
- 提示适配浅色和深色主题，自动避开窗口边缘，可显示在模态弹窗上方；点击、按键、离开按钮、滚动和切换窗口时收起。
- 标签页关闭图标使用可由键盘操作的按钮，并明确标注关闭的文档名称。

版本为开发源码版本，安装包状态以 GitHub Releases 为准。
