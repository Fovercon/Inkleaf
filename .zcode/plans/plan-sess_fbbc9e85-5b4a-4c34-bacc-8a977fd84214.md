# Markdown 阅读器：全自动构建 + 10 轮定时迭代计划

## 总体安排

1. **第 0 轮（计划批准后立即执行，本会话内完成）**：从零搭出完整可用的 MVP
2. **第 1–10 轮（定时任务驱动）**：创建每 1 小时触发一次的定时自动化（`CronCreate`，整点执行，`maxRuns=10`），每轮自动打磨一个主题，对标 Typora / Obsidian / Mark Text
3. 项目内维护 `ITERATION-LOG.md`：记录每轮做了什么、下轮做什么，保证各轮之间无缝衔接；git 初始化并在每轮结束后提交，随时可回滚

## 第 0 轮：MVP（现在就做）

**技术栈**：Electron + TypeScript + esbuild（无前端框架）；CodeMirror 6 编辑器；markdown-it + DOMPurify + highlight.js + @vscode/markdown-it-katex + mermaid（懒加载）；chokidar 文件监听；electron-builder 打包 mac arm64。

**功能范围**（按你已确认的需求）：
- 四面板布局：文件树书库 | 源码编辑 | 实时预览 | 大纲，均可独立收起、可拖宽，布局持久化
- 文件夹书库：递归 .md 文件树、点击即读、外部修改自动刷新、新建文件、在 Finder 中显示
- 编辑：Cmd+S + 自动保存（防抖 2s）、脏状态指示、GFM 语法高亮
- 渲染：表格、任务列表、代码高亮、KaTeX 公式、Mermaid 图表、相对路径图片（自定义 `mdasset://` 协议限定书库根目录内）
- 滚动同步（基于 data-source-line 行号映射）、大纲点击跳转
- 主题：浅色/深色/跟随系统；会话恢复（书库路径、上次文件、滚动位置）

**结构**：`src/main`（窗口/菜单/IPC/协议/持久化）、`src/preload`（contextBridge 安全 API）、`src/renderer`（ui + 渲染管线）。

**验证**：生成覆盖全部语法的测试书库 → 启动应用 → 截图核验布局与渲染。

## 第 1–10 轮迭代路线图（每小时一轮）

每轮流程固定：读 `ITERATION-LOG.md` → WebSearch 调研标杆软件对应功能的实现思路 → 编码实现 → 启动截图验证 → git 提交 → 更新日志 →（UI 有变化则）重新打包。

| 轮次 | 主题 | 对标 |
|------|------|------|
| 1 | 阅读排版体验：字体层级、行宽行距、图片点击放大、链接处理 | Typora 渲染质量 |
| 2 | 编辑体验：列表自动续行、Tab 缩进、快捷键（粗体/斜体/代码块）、剪贴板贴图存为本地文件 | Typora 输入体验 |
| 3 | 导航：大纲增强、返回顶部、最近文件、面包屑 | Obsidian |
| 4 | 文件管理：重命名/删除（移废纸篓）/新建文件夹/树内过滤 | Obsidian 文件管理 |
| 5 | 全书库全文搜索 + Cmd+P 快速切换器 | Obsidian Quick Switcher |
| 6 | 导出 PDF（带排版样式）/ 独立 HTML | Typora 导出 |
| 7 | 主题系统：多套内置主题、自定义 CSS 入口、排版细节 | Typora 主题 |
| 8 | 性能：大文件分段渲染、防抖优化、启动速度 | Mark Text |
| 9 | macOS 集成：.md 文件关联"打开方式"、Dock 菜单、快捷键完备性复查 | 原生体验 |
